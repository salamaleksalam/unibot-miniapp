ТОПЛИВО56 v0.4 — ПРОТОТИП ОБЩЕЙ ЛЕНТЫ

ЧТО РАБОТАЕТ СЕЙЧАС:
* Справочник АЗС Оренбурга, фильтры и карта.
* Чтение данных из старого листа «Показания».
* Новая общая лента «Сообщения водителей» и карточки независимых подтверждений (появится после обновления серверной части).
* Черновики, избранное и настройки — только на устройстве.

ЧТО ПОКА НЕ ВКЛЮЧЕНО:
* Общая отправка сообщений, голосования, реальные уведомления MAX и рейтинг.
* В файле config.js COMMUNITY_WRITES_ENABLED=false (специально для безопасности).
* Серверная часть по умолчанию также блокирует любые пользовательские записи.

1. В Google Таблице «ТОПЛИВО56 — база АЗС» открой Расширения → Apps Script.
2. СОХРАНИ резервную копию прежнего файла Code.gs.
3. Замени содержимое Code.gs текстом из отдельного файла Code_v0_4.gs.
4. Сохрани, выбери функцию setupCommunitySheets и нажми Выполнить.
5. Убедись, что добавились листы «Сообщения» и «Подтверждения».
6. В Развернуть → Управление развертываниями выбери существующее веб-приложение → Изменить (карандаш) → Версия: Новая версия → Развернуть. Тогда URL /exec, как правило, останется прежним.
7. ПЕРЕД обновлением сайта проверь, что старый лист «Показания» продолжает возвращать данные.
8. ФАЙЛЫ мини-приложения (index.html, style.css, app.js, stations.js, stations.csv, config.js) загрузи в корень GitHub Pages, заменив предыдущие версии.
9. Приложение после обновления по-прежнему работает в защищённом режиме чтения и локальных черновиков.

НЕ публикуй токен бота MAX в GitHub и не присылай его в чат.
НЕ ставь COMMUNITY_WRITES_ENABLED=true до полной настройки серверной авторизации, проверки механизма отправки, условий обработки персональных данных и источника законного хранения.

Файлы новой версии для GitHub и код Google Apps Script выдаются РАЗДЕЛЬНО, чтобы не смешать публичные и серверные файлы.
