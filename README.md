# Сигнал рядом — демо MAX Mini App для UniBot

Бот: https://max.ru/se14329885_bot (публичное имя UniBot, @se14329885_bot).

## Что уже работает

- Адаптивный русскоязычный интерфейс внутри MAX или обычного браузера.
- Интерактивная карта OpenStreetMap/Leaflet с условными **центрами регионов** (не координатами происшествий).
- Учебные карточки предупреждения и отмены с очевидной маркировкой «ДЕМО».
- Поиск регионов, выбор и отмена выбора; предпочтения сохраняются через localStorage в данном браузере.
- Переход в UniBot и отображение имени из MAX Bridge (только визуально, **без аутентификации**).

## Что намеренно НЕ подключено

- Нет мониторинга реальных событий или Telegram-источников.
- Нет реальных тревог, официальных подтверждений, геопозиций происшествий.
- Нет серверной базы, Google Таблиц и Google Apps Script.
- Нет доставки персональных уведомлений или публикации в канал MAX.
- Нет защищённой административной панели.

Это **UI-прототип**, а не готовая система оповещения. Ни один пример события не описывает реальную обстановку.

## Публикация бесплатно через GitHub Pages

1. Создайте обычный аккаунт на github.com (если его ещё нет).
2. В GitHub нажмите **New repository**; назовите репозиторий, например, `unibot-miniapp`; выберите **Public**; нажмите **Create repository**.
3. Выберите **Add file → Upload files** и перетащите **содержимое этой папки**: `index.html`, `style.css`, `data.js`, `app.js` (и при желании `README.md`), а не ZIP-архив.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**. В **Build and deployment** выберите **Deploy from a branch** → `main` → `/ (root)` → **Save**.
6. В разделе Pages после публикации появится HTTPS-адрес вида `https://ВАШ-ЛОГИН.github.io/unibot-miniapp/`.
7. Откройте этот адрес сначала в обычном браузере и убедитесь, что видны меню и карта.
8. В платформе MAX для партнёров откройте **Чат-боты → UniBot → ⋮ → Настройки**. Вставьте URL мини-приложения, выберите кнопку «Открыть» и сохраните.
9. Откройте https://max.ru/se14329885_bot в MAX и нажмите новую кнопку мини-приложения.

**Не вставляйте токен бота в файлы, GitHub или в чат.** Репозиторий публичный. Доступ к Bot API должен выполняться только через серверную часть, где токен хранится в секрете.

### Открытие через MAX

MAX Mini App запускается из уже существующего бота, а файлы приложения должны быть доступны по HTTPS. Для интеграции подключён официальный скрипт `https://st.max.ru/js/max-web-app.js`. Внутри MAX используется `window.WebApp`; `initDataUnsafe` допустим только для визуального отображения имени, **не для прав доступа или авторизации**. В будущей серверной части потребуется проверять подпись `initData` по документации MAX.

### Примечания о бесплатных сервисах

GitHub Pages поддерживает публичные репозитории в бесплатном тарифе. Для разработки нужен интернет: библиотека Leaflet и картографические тайлы загружаются с внешних адресов. Используются тайлы `https://tile.openstreetmap.org/{z}/{x}/{y}.png` с указанием авторства и соблюдением политики OSM. При большом числе посетителей потребуется другой провайдер тайлов.

### Структура файлов

- `index.html` — экраны, разметка и подключение MAX Bridge / Leaflet;
- `style.css` — оформление и адаптивная вёрстка;
- `data.js` — список регионов и **только вымышленные демонстрационные события**;
- `app.js` — переключение разделов, карта, поиск, сохранение выбора.
