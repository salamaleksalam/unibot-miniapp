# СИГНАЛ РЯДОМ · MAX Mini App · версия 2

Бот: https://max.ru/se14329885_bot
Приложение: https://salamaleksalam.github.io/unibot-miniapp/

## Что появилось в версии 2

- Получение подтверждённых публичных записей из частной Google Таблицы через Apps Script.
- Таблица работает как первая административная панель: посторонние не могут добавлять публикации.
- Карточки событий с временем и кликабельным первоисточником.
- Обновление ленты и статусов на карте каждые 5 минут при открытом приложении.
- Если связь с базой пропала, приложение показывает ошибку и НЕ выдаёт демо-события за реальные.
- Если события старше 24 часов, статус карты становится неопределённым, а не «безопасно».

НЕТ Telegram-мониторинга, MAX-рассылок, верифицированных серверных подписок. Выбор регионов остаётся на устройстве.

## Шаги настройки (без оплаты)

1. Создать Google Таблицу: https://sheets.new , назвать «UniBot — предупреждения».
2. Расширения → Apps Script.
3. Удалить шаблон из Code.gs и вставить файл `UniBot_Google_Apps_Script_Code.gs` из отдельной загрузки.
4. Вверху выбрать функцию `setupSheets` и нажать «Выполнить», подтвердить запросы доступа Google.
5. Вернуться в Таблицу. Появятся листы «Регионы» и «Публикации» со списками выбора. Образец в строке 2 не опубликован.
6. В Apps Script открыть «Развернуть» → «Новое развертывание» → тип «Веб-приложение»; запускать от имени «Меня», доступ «Все». Сохранить. Скопировать URL формата https://script.google.com/macros/s/XXXXX/exec .
7. В этой сборке `config.js` уже содержит адрес твоего Google Apps Script. Менять его не нужно.
8. Загрузить в корень GitHub репозитория все ШЕСТЬ файлов из нового ZIP, заменив старые, затем открыть MAX Mini App снова.
9. Для проверки добавьте в «Публикации» тестовую строку с реальным официальным URL, но оставьте «Публиковать» = «НЕТ». Когда будете готовы опубликовать настоящее и проверенное событие, переведите на «ДА». При смене значения ID и дата создаются автоматически; для публикации нужны регион, тип, заголовок и HTTPS-ссылка на первоисточник.

**Не делайте саму Google Таблицу публичной.** Публичная ссылка Apps Script предназначена только для чтения уже утверждённых записей. 
**Не загружайте Code.gs в GitHub** (хотя он не содержит секретов) и никогда не загружайте токен MAX в config.js, GitHub или чаты.

## Структура таблицы «Публикации»

| Столбец | Значение |
|---|---|
| A: ID | заполнится автоматически при публикации |
| B: Регион | выпадающий список |
| C: Тип | Предупреждение / Отмена |
| D: Заголовок | название публикации |
| E: Описание | только проверенные сведения; без координат и маршрутов |
| F: Время | дата и время публикации, автоматически при переключении на ДА |
| G: Ссылка на источник | публичная HTTPS-ссылка на официальное уведомление |
| H: Публиковать | НЕТ или ДА |

Появление зелёной отметки означает публикацию сообщения об отмене, а не гарантию отсутствия опасности. Временная отметка на карте отображает условный центр региона, а не место происшествия. Сервис не является официальной системой оповещения.

## Важное

- JSONP-подача сделана исключительно для общедоступной, прошедшей ручную проверку информации. Личные данные через неё не передаются.
- Обслуживание Google Apps Script и бесплатного GitHub Pages ограничено квотами и условиями сервисов; доставка предупреждений не гарантируется в реальном времени.
- Публичный исходный код на GitHub не должен содержать ключи доступа, токены, конфиденциальные данные.
- MAX-уведомления и серверная подписка здесь ещё не реализованы; для них понадобится защищённый бэкенд с проверкой MAX initData и хранением токена в Script Properties.
